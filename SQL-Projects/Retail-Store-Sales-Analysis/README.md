# 🛍 Retail Store Sales Analysis

## 📌 Project Overview

This project uses SQL to analyze retail sales data, customer behavior, and product performance.

---

## 🎯 Business Problem

Retail businesses require data analysis to understand customer purchases, identify top-selling products, and improve profitability.

---

## 🎯 Project Objectives

- Analyze sales performance.
- Identify top-selling products.
- Evaluate customer purchasing behavior.
- Generate business insights using SQL.

---

## 🛠 Tools Used

- SQLite
- SQL

- GROUP BY

## 💡 Key Insights

- Sales vary across product categories.
- Certain customers purchase more frequently.
- Top-performing products contribute significantly to revenue.

---

## ✅ Recommendations

- Increase inventory for high-performing products.
- Develop targeted marketing campaigns.
- Monitor customer purchasing trends regularly.
