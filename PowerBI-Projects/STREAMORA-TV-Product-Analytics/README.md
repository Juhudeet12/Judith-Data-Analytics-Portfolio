# 🎬 STREAMORA TV Product Analytics

## 📌 Project Overview

STREAMORA is a conceptual movie streaming platform created to demonstrate how product analytics can help improve user engagement, content discovery, and business performance.

This project combines business research, data analysis, and Power BI dashboard development to provide insights that support product managers, UI/UX designers, and web developers.

---

## 🎯 Business Problem

Streaming platforms collect large volumes of user and content data. Without proper analysis, it is difficult to understand viewing behavior, engagement, subscription trends, and content performance.

This project demonstrates how analytics can be used to support better product decisions.

---

## 🎯 Project Objectives

- Analyze user engagement.
- Monitor subscription trends.
- Evaluate content performance.
- Identify viewing patterns.
- Build interactive dashboards.
- Provide recommendations for product improvement.

---

## 🛠 Tools Used

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

---

## 📊 Dashboard Features

- KPI Cards
- Watch Time Analysis
- Subscription Analysis
- User Engagement Trends
- Content Performance
- Interactive Filters

---

## 💡 Key Insights

- User engagement varies across different content categories.
- Subscription trends can highlight growth opportunities.
- Popular content drives higher viewing activity.
- Interactive dashboards make performance monitoring easier.

---

## ✅ Recommendations

- Improve content recommendations using viewing behavior.
- Increase engagement through personalized experiences.
- Monitor subscription trends regularly.
- Use analytics to guide UI/UX improvements.
