🏥 Hospital Analytics Dashboard

📌Project Overview
This project analyzes hospital operations using Power BI to provide insights into patient care, operational efficiency, and healthcare performance.
The dashboard helps hospital management monitor key performance indicators (KPIs), identify trends, and support data-driven decision-making.

🎯Business Problem
Hospitals generate large amounts of patient and operational data. Without a centralized dashboard, it can be difficult to monitor performance, identify trends, and make timely decisions.
This project was created to provide an interactive dashboard that tracks hospital performance and highlights areas for improvement.

🎯Project Objectives
- Monitor hospital performance using key metrics.
- Track patient visits over time.
- Analyze patient satisfaction.
- Monitor emergency visit rates.
- Evaluate treatment costs.
- Analyze average length of stay.
- Monitor patient wait times.
- Support management with interactive reports.

🛠 Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

📊Key Performance Indicators (KPIs)
- Total Revenue
- Total Patients
- Patient Satisfaction Score
- Treatment Cost
- Emergency Visit Rate
- Average Length of Stay
- Average Wait Time
- Readmission Rate

🧹Data Preparation
The dataset was prepared using Power Query by:
- Checking for missing values
- Removing duplicate records
- Correcting data types
- Creating relationships between tables
- Creating a Date table
- Creating calculated columns where necessary

📈 Dashboard Features
The dashboard includes:
- KPI Cards
- Monthly Trends
- Patient Analysis
- Revenue Analysis
- Emergency Visit Analysis
- Wait Time Analysis
- Treatment Cost Analysis
- Interactive Filters (Slicers)

💡Key Insights
Examples of insights from the dashboard include:
- Patient visits vary across different months.
- Wait times can indicate opportunities to improve patient flow.
- Treatment costs differ across departments.
- Monitoring satisfaction scores helps identify areas where patient experience can be improved.

✅ Recommendations
- Monitor patient wait times regularly to improve operational efficiency.
- Use satisfaction trends to identify service improvement opportunities.
- Review treatment costs to optimize resource allocation.
- Track emergency visit patterns to support staffing and planning.
