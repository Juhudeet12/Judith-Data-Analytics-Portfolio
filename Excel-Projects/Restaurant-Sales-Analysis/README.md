# 🍽 Restaurant Sales Analysis

## 📌 Project Overview

This project analyzes restaurant sales data using Microsoft Excel to identify revenue trends, customer purchasing behavior, and operational performance.

---

## 🎯 Business Problem

Restaurant managers need accurate sales reports to understand customer demand, identify top-performing staff, and improve business performance.

---

## 🎯 Project Objectives

- Analyze sales performance.
- Track revenue trends.
- Evaluate server performance.
- Monitor customer purchasing behavior.

---

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting

---

## 📊 Dashboard Features

- Revenue Dashboard
- Monthly Sales Trends
- Top Performing Servers
- Customer Insights

---

## 💡 Key Insights

- Revenue fluctuates across different periods.
- Some servers consistently outperform others.
- Certain menu items contribute more to overall sales.

---

## ✅ Recommendations

- Focus promotions on high-performing products.
- Reward top-performing staff.
- Use sales trends for inventory planning.
