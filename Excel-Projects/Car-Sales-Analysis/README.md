# 🚗 Car Sales Data Analysis

## 📌 Project Overview

This project analyzes car sales data using Microsoft Excel to identify sales trends, top-performing car models, revenue patterns, and customer purchasing behavior. The analysis provides valuable insights that can help a car dealership improve sales performance and make informed business decisions.

---

## 🎯 Business Problem

Car dealerships generate large amounts of sales data every day. Without proper analysis, it can be difficult to identify top-selling vehicles, monitor revenue performance, and understand customer purchasing patterns.

This project demonstrates how Microsoft Excel can be used to transform raw sales data into meaningful business insights.

---

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify top-selling car models.
- Monitor revenue trends.
- Compare sales performance across different vehicle types.
- Create an interactive dashboard for decision-making.

---

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Excel Functions
- Slicers

---

## 📊 Dashboard Features

- Total Sales
- Total Revenue
- Top-Selling Car Models
- Sales by Vehicle Type
- Monthly Sales Trends
- Interactive Filters (Slicers)

---

## 🧹 Data Cleaning

The dataset was cleaned by:

- Checking for missing values
- Removing duplicate records
- Correcting data formats
- Formatting dates
- Standardizing text values
- Creating calculated columns where necessary

---

## 💡 Key Insights

Examples of insights from the dashboard include:

- Certain car models consistently generated the highest sales.
- Revenue varied across different vehicle categories.
- Sales trends changed throughout the reporting period.
- Some vehicle types contributed more to total revenue than others.

---

## ✅ Recommendations

- Increase inventory for top-selling car models.
- Develop marketing campaigns for lower-performing vehicle categories.
- Monitor monthly sales trends to improve inventory planning.
- Focus promotions on high-revenue vehicle segments.
